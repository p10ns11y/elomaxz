# Original elm-c v0.1 (Legacy Reference)

This is the **original starting point** of our evolution — the simple, clean elm-c v0.1 that began this journey.

It has been preserved inside `elomaxz/legacy/elm-c/` to honor where we started.

## Quick Start

```bash
make
./bin/counter
```

Or:

```bash
make run
```

Build output goes to `bin/`.

See [`docs/cheat-sheet.md`](docs/cheat-sheet.md) for a C refresher focused on the elm-c patterns.

**Key differences from current elomaxz**:
- No `Cmd` system
- No hybrid architecture
- Simpler `ElmProgram` (just function pointers)
- Great for learning the basics

We evolved from this clean foundation into the powerful hybrid framework you see today.
